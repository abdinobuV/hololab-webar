# 📡 NetGO WebAR — 10 Karakter Jaringan TJKT Kelas X + Galeri Koleksi Net-Dex

Aplikasi game edukasi berbasis **WebAR** ala **Pokémon GO** untuk siswa **Kelas X TJKT / TKJ**: aktifkan kamera HP, temukan & sentuh **10 Karakter Jaringan 3D Interaktif**, baca penjelasan materi *live* di atas layar kamera, lempar **Net-Ball**, dan lengkapi **Galeri Koleksi Net-Dex (10/10)**!

---

## 🌟 10 Karakter Jaringan 3D Interaktif
1. 📡 **Router** *(Rare)* — Port WAN (Biru) vs Port LAN (Kuning) + animasi paket IP
2. 🔀 **Switch 8-Port** *(Common)* — Forwarding frame spesifik berbasis MAC Address
3. 📶 **Access Point (Wi-Fi)** *(Common)* — Simulasi gelombang 2.4 GHz (jauh) vs 5 GHz (cepat)
4. 🖥️ **Server & Rack** *(Epic)* — Simulasi layanan DHCP, DNS, dan Web Server
5. 🔌 **Kabel UTP & RJ-45** *(Common)* — Mode Bedah / Explode 3D 4 pasang pilin & 8 pin emas
6. ✨ **Kabel Fiber Optic** *(Rare)* — Mode Bedah Lapisan (Jacket, Coating, Cladding, Core) + pulsa cahaya laser
7. ⭐ **Topologi Star** *(Rare)* — Simulasi Normal, 1 Kabel Putus, & Switch Pusat Rusak
8. 🚌 **Topologi Bus** *(Common)* — Kabel Backbone + 2 Terminator + simulasi Backbone Putus
9. ⭕ **Topologi Ring** *(Rare)* — Jalur melingkar + aliran Token searah + simulasi 1 Jalur Putus
10. 🛡️ **Firewall Shield** *(Legendary)* — Perisai penyaring paket Hijau (Lolos) vs paket Merah (Serangan Diblokir!)

## 🏆 Galeri Koleksi (Net-Dex)
- Progress bar (`0/10 → 10/10`), sistem pangkat (*Pemula Jaringan → Master TJKT*), filter kategori (*Perangkat, Media, Topologi, Keamanan*), tombol **Radar Acak (`🎲`)**, dan penyimpanan progress otomatis via `localStorage`.
