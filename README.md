# 📡 NetGO WebAR — 13 Karakter Jaringan TJKT Kelas X + Zoom 3D & Galeri Koleksi

Aplikasi game edukasi berbasis **WebAR** ala **Pokémon GO** untuk siswa **Kelas X TJKT / TKJ**: aktifkan kamera HP, perbesar/perkecil karakter dengan **cubit 2 jari (Pinch-to-Zoom)** atau tombol **`＋ / －`**, baca penjelasan materi *live* di atas kamera, lempar **Net-Ball**, dan lengkapi **13/13 Karakter** di Galeri Koleksi Net-Dex!

---

## 🌟 13 Karakter Jaringan 3D Interaktif
### Perangkat Jaringan (4)
1. 📡 **Router** *(Rare)* — Port WAN (Biru) vs Port LAN (Kuning) + animasi paket IP
2. 🔀 **Switch 8-Port** *(Common)* — Forwarding frame spesifik berbasis MAC Address
3. 📶 **Access Point (Wi-Fi)** *(Common)* — Gelombang sinyal 2.4 GHz (jauh) vs 5 GHz (cepat)
4. 🖥️ **Server & Rack** *(Epic)* — Simulasi layanan DHCP, DNS, dan Web Server

### Media Transmisi (2)
5. 🔌 **Kabel UTP & RJ-45** *(Common)* — Mode Bedah / Explode 3D 4 pasang pilin & 8 pin emas
6. ✨ **Kabel Fiber Optic** *(Rare)* — Mode Bedah Lapisan (*Jacket, Coating, Cladding, Core*) + pulsa cahaya laser

### Topologi Jaringan Lengkap (6)
7. ⭐ **Topologi Star** *(Rare)* — Simulasi Normal, 1 Kabel Putus, & Switch Pusat Rusak
8. 🚌 **Topologi Bus** *(Common)* — Kabel Backbone + 2 Terminator + simulasi Backbone Putus
9. ⭕ **Topologi Ring** *(Rare)* — Jalur melingkar + aliran Token searah + simulasi 1 Jalur Putus
10. 🕸️ **Topologi Mesh** *(Epic)* — Koneksi Full Mesh + simulasi 1 Jalur Putus (**Auto Reroute** lewat jalur cadangan!)
11. 🌳 **Topologi Tree** *(Rare)* — Hierarki Root Switch → 2 Sub-Switch → 4 Klien + simulasi cabang/root rusak
12. 🔀 **Topologi Hybrid** *(Legendary)* — Gabungan Topologi Star + Ring lewat Router penghubung

### Keamanan Jaringan (1)
13. 🛡️ **Firewall Shield** *(Legendary)* — Perisai penyaring paket Hijau (Lolos) vs Merah (Serangan Diblokir!)
