📘 Ensiklopedia Jaringan Dasar

1. ROUTER

Pengatur Jalur Paket Data (IP)

Router berfungsi menghubungkan dua atau lebih jaringan yang berbeda dan mengatur jalur pengiriman paket data berdasarkan alamat IP.

Perbedaan Port WAN & Port LAN:
  • Port WAN (Biru): Menghubungkan router ke jaringan luar / modem ISP (Internet).
  • Port LAN (Kuning): Menghubungkan perangkat di dalam jaringan lokal (Switch, PC, Laptop).
2. SWITCH

Penghubung Jaringan Lokal (LAN)

Switch menghubungkan berbagai perangkat dalam satu jaringan lokal (LAN) dan meneruskan data ke perangkat tujuan secara spesifik menggunakan MAC Address.

3. ACCESS POINT (WI-FI)

Pemancar Jaringan Nirkabel (WLAN)

Access Point memancarkan sinyal gelombang radio Wi-Fi (2.4 GHz / 5 GHz) agar smartphone dan laptop dapat terhubung ke jaringan lokal (LAN) tanpa kabel.

4. SERVER & RACK

Penyedia Layanan Jaringan

Server menyediakan layanan jaringan bagi klien, seperti Web Server, DNS, DHCP (pemberi IP otomatis), dan penyimpanan data terpusat.

5. KABEL UTP & KONEKTOR RJ-45

Media Transmisi Tembaga Terpilin

Kabel UTP (Unshielded Twisted Pair) adalah media transmisi kabel tembaga 4 pasang (8 utas) berpasangan terpilin untuk meredam interferensi, dengan ujung konektor RJ-45.

6. KABEL FIBER OPTIC

Transmisi Cahaya Kecepatan Tinggi

Fiber Optic menggunakan serat kaca/plastik ultra-halus yang mengirimkan data berupa pulsa cahaya. Jarak jangkauannya sangat jauh dan kebal interferensi elektromagnetik.

1. TOPOLOGI STAR (BINTANG)

Terpusat di Satu Switch / Hub

Seluruh perangkat (PC, Laptop, Printer) terhubung terpusat ke satu Switch/Hub.

  • ✅ Mudah Dikelola: Gangguan cepat diidentifikasi karena tiap klien punya jalur sendiri.
  • ✅ Isolasi Kabel: Jika 1 kabel klien putus, klien lain tetap berkomunikasi normal.
  • ⚠️ Risiko Pusat: Jika perangkat pusat (Switch) rusak, seluruh jaringan terganggu.
2. TOPOLOGI BUS

Satu Jalur Backbone + Terminator

Semua perangkat menempel pada satu kabel utama (backbone) dengan Terminator di kedua ujung untuk mencegah pantulan sinyal. Hemat kabel, namun jika kabel utama putus seluruh jaringan lumpuh.

3. TOPOLOGI RING (CINCIN)

Jalur Melingkar Berbasis Token

Setiap komputer terhubung ke dua tetangganya membentuk lingkaran tertutup. Data mengalir satu arah lewat Token, minim tabrakan, tetapi rentan jika satu segmen jalur putus.

4. TOPOLOGI MESH (JALA)

Saling Terhubung Penuh dengan Jalur Cadangan

Setiap perangkat terhubung langsung ke banyak/semua perangkat lain (Full Mesh). Sangat andal karena jika 1 kabel putus data otomatis berbelok lewat jalur cadangan, namun butuh banyak kabel.

5. TOPOLOGI TREE (POHON)

Struktur Hierarki Bertingkat

Menggabungkan tulang punggung dengan cabang Star secara hierarkis dari Root Switch ke Sub-Switch tiap lantai/lab. Mudah diperluas, tetapi gangguan pada Root memutus komunikasi antar cabang.

6. TOPOLOGI HYBRID (CAMPURAN)

Gabungan Dua atau Lebih Topologi

Memadukan dua atau lebih topologi berbeda (misalnya Star + Ring dihubungkan oleh Router/Bridge) sehingga fleksibel untuk jaringan sekolah, kampus, atau perusahaan besar.

7. FIREWALL (KEAMANAN JARINGAN)

Perisai Penyaring Lalu Lintas Data

Firewall menyaring paket data masuk/keluar sesuai aturan keamanan — meloloskan akses sah dan memblokir serangan siber atau akses ilegal.
