MATERI KELAS X TJKT / TKJ

Ensiklopedia Jaringan Dasar

1. ROUTER

Pengatur Jalur Paket Data (IP)

Router berfungsi menghubungkan dua atau lebih jaringan yang berbeda dan mengatur jalur pengiriman paket data berdasarkan alamat IP.

Perbedaan Port WAN & Port LAN:
  • Port WAN (Biru): Menghubungkan router ke jaringan luar / modem ISP (Internet).
  • Port LAN (Kuning): Menghubungkan perangkat di dalam jaringan lokal (Switch, PC, Laptop).
2. SWITCH

Penghubung Jaringan Lokal (LAN)

Switch menghubungkan berbagai perangkat dalam satu jaringan lokal (LAN) dan meneruskan data ke perangkat tujuan secara spesifik menggunakan MAC Address.

3. ACCESS POINT (WI-FI)

Pemancar Jaringan Nirkabel (WLAN)

Access Point memancarkan sinyal gelombang radio Wi-Fi (2.4 GHz / 5 GHz) agar smartphone dan laptop dapat terhubung ke jaringan lokal (LAN) tanpa kabel.

4. SERVER & RACK

Penyedia Layanan Jaringan

Server adalah komputer berperforma tinggi yang menyediakan layanan bagi perangkat klien, seperti Web Server, DNS, DHCP (pemberi IP otomatis), dan penyimpanan data terpusat.

5. KABEL UTP & KONEKTOR RJ-45

Media Transmisi Tembaga Terpilin

Kabel UTP (Unshielded Twisted Pair) adalah media transmisi kabel tembaga 4 pasang (8 utas) berpasangan terpilin untuk mengurangi interferensi, dengan ujung konektor RJ-45.

6. KABEL FIBER OPTIC

Transmisi Cahaya Kecepatan Tinggi

Fiber Optic menggunakan serat kaca/plastik ultra-halus yang mentransmisikan data dalam bentuk pulsa cahaya. Jarak jangkauannya sangat jauh (kilometer) dan kebal terhadap gangguan elektromagnetik.

1. TOPOLOGI STAR (BINTANG)

Terpusat di Satu Switch / Hub

Seluruh perangkat (PC, Laptop, Printer) terhubung terpusat ke satu Switch/Hub.

  • ✅ Mudah Dikelola: Gangguan cepat diidentifikasi karena tiap klien punya jalur sendiri.
  • ✅ Isolasi Kabel: Jika 1 kabel klien putus, klien lain tetap berkomunikasi normal.
  • ⚠️ Risiko Pusat: Jika perangkat pusat (Switch) rusak, seluruh jaringan terganggu.
2. TOPOLOGI BUS

Satu Jalur Backbone + Terminator

Semua perangkat terhubung ke satu kabel utama (backbone) dengan Terminator di kedua ujung untuk menyerap sinyal agar tidak memantul. Hemat kabel, namun jika kabel utama putus maka seluruh jaringan lumpuh.

3. TOPOLOGI RING (CINCIN)

Jalur Melingkar Berbasis Token

Setiap komputer terhubung ke dua tetangganya membentuk lingkaran tertutup. Data mengalir satu arah menggunakan mekanisme Token, sehingga minim tabrakan data (*collision*), tetapi rentan jika satu segmen jalur terputus.

4. TOPOLOGI MESH (JALA)

Saling Terhubung Penuh dengan Jalur Cadangan

Pada Topologi Mesh, setiap perangkat terhubung langsung ke beberapa atau semua perangkat lain (*Full Mesh*). Sangat andal (*fault tolerant*) karena jika 1 kabel putus, paket data otomatis mencari jalur cadangan lain; namun membutuhkan sangat banyak kabel dan biaya tinggi.

5. TOPOLOGI TREE (POHON)

Struktur Hierarki Bertingkat

Topologi Tree menggabungkan struktur tulang punggung dengan cabang-cabang Star secara hierarkis (dari Switch Root utama di puncak ke Sub-Switch di tiap lantai/ruang lab). Mudah diperluas, tetapi gangguan pada Root utama dapat memutus komunikasi antar cabang.

6. TOPOLOGI HYBRID (CAMPURAN)

Gabungan Dua atau Lebih Topologi

Topologi Hybrid memadukan dua atau lebih jenis topologi berbeda (misalnya Topologi Star di gedung A dihubungkan dengan Topologi Ring di gedung B lewat Router/Bridge) sehingga sangat fleksibel untuk jaringan skala besar.

7. FIREWALL (KEAMANAN JARINGAN)

Perisai Penyaring Lalu Lintas Data

Firewall bertugas mengawasi dan menyaring paket data masuk maupun keluar berdasarkan aturan keamanan — meloloskan akses yang sah dan memblokir serangan siber / akses ilegal.
